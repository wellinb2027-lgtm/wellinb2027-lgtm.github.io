How to Embed a YouTube Video

Follow these steps to place a service-hosted video directly on a webpage.

What does embedding mean?

Embedding lets visitors watch a video on your webpage without having to leave your site. In this tutorial, I will use a public European Space Agency video called Earth Views from Space.

Before you begin: Open YouTube in your browser and make sure the video you choose has embedding enabled. The video used in this example is also included at the bottom of this page.

STEP 1

Open the video on YouTube

Go to YouTube and search for the video you want to use. Select the video so it opens on its own watch page. Check that it is appropriate for your audience.

Example: Earth Views from Space.

STEP 2

Select the Share button

Under the video player, click Share. A sharing window will open with different ways to share the video.

STEP 3

Choose the Embed option

In the sharing window, select Embed. YouTube will display an HTML iframe code snippet. If the Embed option is missing, the uploader may have disabled embedding, so choose a different video.

STEP 4

Copy the iframe code

Review the preview and options, then click Copy to copy the iframe code. The code tells the browser where the video player is hosted and how large it should appear.

STEP 5

Paste the code into your HTML

Open your HTML file in your code editor. Paste the copied iframe code where you want the video to appear, usually inside the <body> section. Save the file and open the webpage in a browser to test it.

You can place the iframe inside a <div> to make it easier to style. Keep the iframe's src value exactly as YouTube provides it.

Example: Embedded video

This is the same Earth-views video used for the example. It is embedded below so visitors can watch it directly on this webpage.

Video: European Space Agency, “Earth views from space.”

You're finished!

After testing the page, upload the HTML file, CSS file, and screenshot images to the same GitHub repository. Make sure the folder names and image file names match the paths in the HTML.
