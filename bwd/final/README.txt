OLIVET HIGH SCHOOL THEATRE WEBSITE PROJECT

Six pages: index.html, productions.html, auditions.html, backstage.html, learning.html, contact.html.
All pages use the shared external style.css file.

Included requirements:
- Six linked pages and responsive navigation
- External stylesheet, div-based layouts, Flexbox and CSS Grid
- Semantic HTML, skip link, responsive design and keyboard focus styles
- Original lightweight SVG visual on every page with alt text and caption
- Simple and nested lists
- Styled complex table with caption, headers and row headings
- Sample contact form with four controls
- Descriptive internal and external links
- CSS animation with text description and prefers-reduced-motion support
- Description metadata for search engines

IMPORTANT:
This is a student-made demonstration, not an official school website. School-specific dates, contact details and audition information have not been verified. Get approval from the school/theatre director and replace sample content with approved information. Use logos and student photographs only with permission. The contact form is a demonstration and does not send or store messages.

To use: keep all HTML files, style.css and the images folder together. Open index.html in a browser. Upload the entire project to GitHub and test the published site before submitting.
